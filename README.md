# Find-my-college: «Куда поступить»

Сайт-подборщик колледжей и вузов Санкт-Петербурга. Человек вводит средний балл аттестата (колледж, после 9 класса) или сумму баллов ЕГЭ (вуз, после 11 класса), выбирает профессию, листает карточки свайпом и сравнивает понравившиеся варианты по цене, баллу, времени в пути и оценке качества.

Сайт опубликован через GitHub Pages: https://ponluti472-coder.github.io/Find-my-college-/

## ⚠️ Статус данных

**Сейчас все данные демонстрационные.** Баллы, цены, оценки качества, время в пути и описания придуманы для показа интерфейса. Названия части вузов реальные, но цифры к ним не имеют отношения к действительности. Не использовать для реального выбора и не выдавать за достоверную информацию, пока не будет заменено реальными данными с указанием источников.

## Структура проекта

```
index.html      — каркас страницы, подключает остальные файлы
css/style.css   — все стили
js/app.js       — логика и интерфейс (экраны, свайп, сравнение)
data/data.js    — ВСЕ данные: профессии, колледжи, вузы, предложения
README.md       — этот файл
```

Чтобы обновить информацию на сайте, достаточно править только `data/data.js`. В `js/app.js` и `css/style.css` лезть для этого не нужно.

## Формат данных (`data/data.js`)

Связи между списками идут **по номеру элемента, начиная с нуля**.

| Переменная | Что это | Поля |
|---|---|---|
| `P` | профессии | `n` название, `e` эмодзи, `g` цвета градиента, `s` специальность, `d` короткое описание |
| `PI` | тексты о профессии (тот же порядок, что в `P`) | `[что делает, почему может подойти, что важно знать]` |
| `EXS` | предметы ЕГЭ по профессиям (тот же порядок, что в `P`) | список предметов |
| `C` | колледжи | `[название, метро, x, y, оценка качества, описание]` |
| `UC` | вузы | те же поля, что у `C` |
| `H` | станции «где вы живёте» | `'название': [x, y]` |
| `O` | предложения колледжей | `[профессия, колледж, средний балл прошлого года, бюджет (1/0), цена в год, пометка]` |
| `UO` | предложения вузов | `[профессия, вуз, сумма ЕГЭ за 3 экзамена (из 300), бюджет (1/0), цена в год, пометка]` |

Пояснения:
- В `O` и `UO` число в начале строки: номер профессии в `P`, затем номер колледжа в `C` (или вуза в `UC`).
- `x`, `y` это условные координаты на плоскости, по ним считается примерное время в пути. Реальный расчёт по картам пока не подключён.
- Для платных мест бюджет `0`, цена указывается в рублях за год. Для бюджетных цена `0`.
- Пометка (необязательное последнее поле) выводится на карточке, например «нужна медсправка».
- Если удалить элемент из середины списка `C`, `UC` или `P`, номера всех следующих сдвинутся, и строки в `O` и `UO` нужно будет поправить. Безопаснее добавлять новые элементы в конец.

## Как посмотреть на своём компьютере

Достаточно открыть `index.html` двойным кликом: сборка и сервер не нужны.

## Как опубликовать изменения

1. Загрузить изменённые файлы в репозиторий (с сохранением папок `css`, `js`, `data`).
2. GitHub Pages обновит сайт в течение пары минут.

Перед каждой крупной правкой делайте отдельный коммит, чтобы можно было откатиться.
